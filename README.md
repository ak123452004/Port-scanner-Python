# 🔎 Python Port Scanner

A simple beginner-friendly TCP Port Scanner built with Python.

This project uses Python's built-in `socket` module to check whether
TCP ports are open on a target host.

## ⚠️ Disclaimer

Use this tool only on:

- Your own computer
- Your own server
- Systems where you have explicit permission to perform security testing

Unauthorized port scanning may violate laws, policies, or terms of service.

## 🚀 Features

- Scan TCP ports
- Scan a specific range of ports
- Accept IP addresses or hostnames
- Display open ports
- Simple command-line interface
- No external Python libraries required

## 🛠️ Technologies

- Python 3
- Socket Programming
- Command Line Interface
